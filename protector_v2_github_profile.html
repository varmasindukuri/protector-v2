Key features
14-agent fusion
Weighted majority vote across classical ML, deep learning, HMM, and clustering agents with stacked meta-learner.
SHAP + GradCAM
Per-prediction SHAP values with beeswarm plots and GradCAM attention heatmaps for CNN sequence decisions.
Attack family CLF
Classifies every alert into BruteForce, DoS/DDoS, Malware, WebAttack, or Normal using a trained family RF.
NetworkX topology
Dark-themed directed process-connection graph showing live process→IP edges, colored by CPU intensity.
Static file analysis
PE header audit, section entropy, suspicious imports, YARA rules, packer detection, and shellcode chunk scan.
C2 beacon detection
Monitors live connections for periodic beaconing patterns using IsolationForest + interval regularity scoring.
Groq LLM Q&A
Natural language security Q&A with live agent context injected — llama-3.3-70b-versatile, no cloud data leak.
Vulnerability assessment
Scans exposed ports against known dangerous services and running process names against a suspicious tool list.
Alerts + auto-start
Desktop notifications + email for critical events. VBS launcher in Windows Startup — runs at boot, no Jupyter needed.
